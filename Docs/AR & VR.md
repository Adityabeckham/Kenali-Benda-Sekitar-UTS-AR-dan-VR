- 2. Beri nama project: AR_Nama Mahasiswa_NIM

- 4. Project Unity (ditujukan pada dosen saat pertemuan)

## A. Skenario Soal

Buat aplikasi "Kenali Benda Sekitar", yaitu aplikasi AR edukasi sederhana. Ketika kamera diarahkan ke gambar target (Image Target), aplikasi akan menampilkan objek 3D beserta informasi pendukungnya.

## B. Tugas Praktek

## Tugas 1: Persiapan Project

- 1. Buat project Unity baru (template 3D).

- 2. Aktifkan dukungan AR (Vuforia Engine atau AR Foundation + ARCore).

- 3. Atur Build Settings ke platform Android.

- 4. Ganti nama scene menjadi MainAR.

## Tugas 2: Konfigurasi AR Camera dan Image Target

- 1. Hapus Main Camera bawaan, ganti dengan AR Camera.

- 2. Masukkan Vuforia atau konfigurasi AR Session dan XR Origin (AR Foundation).

- 3. Import database gambar.

- 4. Tambahkan minimal 2 Image Target dengan gambar yang berbeda.

## Tugas 3: Menampilkan Objek 3D

- 1. Import model 3D.

- 2. Jadikan objek 3D sebagai child dari masing-masing Image Target.

- 3. Atur posisi, rotasi, dan skala agar objek tampil proporsional di atas target.

- 4. Pastikan objek hanya muncul saat target terdeteksi.

## Tugas 4: Animasi dan Interaksi

- 1. Buat script C# sederhana agar objek 3D berputar otomatis (rotasi sumbu Y).

- 2. Tambahkan teks 3D / Canvas World Space berisi nama objek di atas model.

## Tugas 5: Antarmuka Pengguna (UI)

- 1. Buat Canvas (Screen Space) dengan minimal 2 tombol:

- Tombol "Keluar" (menutup aplikasi dengan Application.Quit()).

- Tombol "Tampilkan/Sembunyikan Info" untuk mengaktifkan dan menonaktifkan panel informasi.

- 2. Susun tata letak UI agar rapi dan terbaca jelas di layar ponsel.

## Tugas 6: Build dan Pengujian

- 1. Lakukan Build menjadi file .apk.

- 2. Instal dan uji aplikasi di smartphone Android.

- 3. Tunjukkan hasil kepada dosen: target terdeteksi, objek tampil, objek berputar, dan tombol berfungsi.
